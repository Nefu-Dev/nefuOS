# 体素沙盒（voxel_play.html）

nefuOS 自研浏览器栈上的可游玩体素世界，作为 bloxd.io 3D 世界的自建替代方案。

## 文件

`verify_out\voxel_play.html` — 单文件，无外部依赖，无网络请求。

## 在 nefuOS 浏览器里怎么打开

在地址栏输入本地路径：

```
file:///verify_out/voxel_play.html
```

（按 nefuOS 实际的根路径调整；该文件已放在 `verify_out\` 下。）

## 操作

| 键 | 作用 |
| --- | --- |
| W / A / S / D | 前后左右移动 |
| Q / E | 降低 / 抬高视点 |
| 空格 | 跳跃 |
| 鼠标拖拽 | 转头（yaw / pitch） |
| G | 挖掉准星对准的方块（该列高度 -1） |
| F | 在准星位置放一个方块（该列高度 +1，上限 8），使用当前选中的材质 |
| 1 / 2 / 3 | 切换放置材质：草 / 石 / 砖（HUD 会显示当前选中项） |
| R | 重置地形（重新生成整个世界，挖坏的地方一次性恢复） |

准星固定在屏幕中央，射线沿视线以 0.05 步长前进、最多 400 步（20 个世界单位）。

**准星会告诉你瞄到了什么**：光线追踪到可达方块时准星转成琥珀色（`#ffd24a`），空手无目标时是白蓝色（`#e8f0ff`）；HUD 里同步显示 `aim x,z h=列高` 或 `nothing in reach`。挖和放之前先看一眼准星，就不会打空。

## 世界参数

| 项 | 值 |
| --- | --- |
| 地形 | 64 × 64 高度场（4096 列），列高 1–7（实测 min=1 max=7，无空列） |
| 网格 | 43272 顶点，1 次 `drawArrays` 每帧，实测 56 fps |
| 材质 | 顶面草绿 / 侧壁土褐；列高 ≥ 3 自动转岩石灰（顶面灰、侧壁深灰）；手工放置可选草/石/砖 |
| 取景 | 1280 × 720 canvas，透视 fovy 1.05，near 0.1 / far 120 |
| 雾 | `(到相机距离 - 10) / 70`，最远 cap 到 0.92 并混入天空色；近处 10 单位内完全不糊 |
| 底板 | y = -0.6 的深色平面，让开阔边缘读作浮空岛而非地面破洞 |
| 相机 | 眼高 2.6（能跨 2–3 格高差），起点 (0, 6, 8)，落地后钳制到该列顶面 + 2.6 |

## 已验证（实测，非静态审查）

在独立浏览器后端（Chrome 147）跑通并逐项确认：

| 项 | 实测证据 |
| --- | --- |
| 渲染 | `[VX] first frame drawn, verts=8898`，画面立体台地、侧面明暗、草地格纹、远处雾化 |
| 帧率 | HUD 稳定 `~56 fps` |
| 破坏 | `[VX] dig 12,13 h=0`，顶点增加（挖开暴露新内壁面），画面出现坑洞 |
| 放置 | `[VX] place 12,11 h=2` → `h=3`，准星前立起两格高柱子 |
| 移动 | `pos` 由 `6.3,4.2,-1.7` 走到 `6.3,4.2,-11.2` |
| 跳跃 | `[VX] jump`，`pos` 由 `0,2.2,8` 升到 `0,4.3,8` |

## 尚未验证

**在 nefuOS 自身 swgl 栈上的运行**。当前所有实测都在独立浏览器后端完成。代码侧已刻意只用之前探针验证过的路径：

- `STATIC_DRAW`（未用 `DYNAMIC_DRAW`）
- 单次 `drawArrays(TRIANGLES)`
- `uniformMatrix4fv`
- 4 个顶点 attribute（`p` / `uv` / `n` / `col`）
- 16×16 `Uint8Array` 纹理 + `NEAREST` 过滤
- 无 `Float64Array`、无扩展、无 `texImage2D` 的 DOM 重载

验证脚本 `tools\_voxel_verify.ps1` 已写好，判据：console 出现 `[VX] first frame drawn`，且截图草绿像素 > 2 万、天蓝像素 > 10 万。执行通道恢复后跑一次即可补上这一格。

## 为什么不做官方 bloxd

见 `docs\browser-parity-status.md` 的 4.11.7。要点：

1. `/play/<game>` 才是 3D 世界地址，`/game/<game>` 只是游戏选择页。
2. bloxd 的 3D 引擎是 WASM 模块，页面要先把它拉下来。
3. 该 WASM 单独请求能取回（211697 字节），但页面内加载反复 `stalled`，`/play/` 页最终把主线程占死到**连截图都不可响应**——真 Chrome 147 同样如此。
4. 另有 `/social/bloxd-matchmake` 全 401 的 Turnstile 会话门。

两道门叠加，因此改用自建世界。
